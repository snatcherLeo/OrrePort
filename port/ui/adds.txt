# "What OrrePort adds" (Settings › About): the order of its sections and rows (5.13, 2026-11-24).
#
# Why a data file: every list OrrePort adds to the game's look is data the UI Editor can later change (snatcherLeo,
# 2026-11-15), not order hard-coded in the program. The words are ui/lang keys (adds.*), so the list reads in every
# language; pc_whatadds.cpp turns this file into the window's list. Keep it in step with the public page
# (docs/public-repo/what-orreport-adds.md in the private repo; docs/what-orreport-adds.md in the public one).
#
# One entry per line ("#" starts a note):
#   section <id>                     a heading: adds.sec.<id>
#   row <id> <sub> <where> <acc>     a change: its name adds.<id>, then
#                                      <sub>   sub = a detail line adds.<id>.sub, - = none
#                                      <where> always = adds.where.always, own = adds.<id>.where, - = none
#                                      <acc>   off / same / look = adds.acc.<that>, own = adds.<id>.acc, - = none
#   note <id>                        a plain paragraph: adds.<id>
