# OrrePort's words in English: the source for every translation.
#
# HOW TO TRANSLATE (thank you!)
#   1. Copy this file and name the copy with your language's code: de.txt (German), fr.txt (French), es.txt (Spanish),
#      pt-BR.txt (Brazilian Portuguese), ja.txt (Japanese), and so on. Keep it in this folder (ui/lang/).
#   2. Change only the text AFTER each "=". Never change the key before it (the part with the dots).
#   3. Save it as UTF-8 (most editors do; in Notepad choose "UTF-8" when saving).
#   4. Set the "language.name" and "plural" lines below for your language.
#   5. Start OrrePort: it picks your file when Windows is set to your language, or set "language = de" (your code) in
#      user/settings.ini. No rebuild, nothing to install.
#   6. Check your file: python tools/local/lang_check.py de  (lists missing lines, extra lines and broken {names}).
#   Anything you leave out shows in English, so a half-done file is fine to share.
#
# RULES FOR THE TEXT
#   {name}  OrrePort puts a value there (a file name, a number, a date). Keep it exactly as written, braces included;
#           you may move it anywhere in the sentence.
#   \n      starts a new line.
#   "#"     at the start of a line is a note for translators, like this one. Notes say where a text shows and, for
#           tight spots, how long it may be ("short").
#   Button names printed on controllers (A, B, X, Y, L, R, START) are not in this file: they stay as they are.
#   Please don't use < or & in a text (the screens would read them as layout).
#   Test your layout: set "language = pseudo" to see every text made longer and accented, so you can spot what is cut off.
#
# COUNTS ("1 picture", "5 pictures")
#   A text with a count has a line per form: key.one, key.few, key.many, key.other. Which forms your language uses is
#   set by "plural" below:
#     one-other     1 is "one", everything else "other" (English, German, Spanish, Italian, Dutch, Swedish, ...)
#     french        0 and 1 are "one" (French, Brazilian Portuguese)
#     east-slavic   one / few / many (Russian, Ukrainian, Belarusian)
#     polish        one / few / many (Polish)
#     czech         one / few / other (Czech, Slovak)
#     none          only "other" (Japanese, Chinese, Korean)
#   Write the forms your language needs; a missing form uses "other".
